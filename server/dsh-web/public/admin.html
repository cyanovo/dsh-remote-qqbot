后台管理

用管理员账号登录。登录后所有请求走 cookie，看得见是谁在操作。

普通账号会被拒（403）。口令不受影响，连打多少次都不会锁。

口令在服务器的 /var/lib/dsh-web/admin-token 里（首次启动自动生成）。
它是一串十六进制字符；连错 10 次会锁 10 分钟。

最近 14 天

柱高按这 14 天里最高的那天算。每天一行：查看次数 / 新增用户 / 新增记录。

用户

口令、档位、用量都在这儿；但看不到任何人的正文。

点每行最右边的「管理」，就能给 TA 加 Pro / 取消 Pro / 封禁·解封 / 重置密码 / 删除账号； 点用户名进的是同一处。

新建账号

天数留 0 就是免费版（100 次/天 · 留 5 小时）。

记录

只给元信息：谁、什么时候、多长、什么时候过期。

后台读不到任何人的正文：服务端在列表接口里就没返回 text 字段。 口令泄露也不会带出用户写过什么。要看正文只能本人登录。

兑换码

付费版（Pro）= 每天 1000 次 + 记录保留 48 小时；兑换是叠加，天数往后加。

生成

没有在线支付。怎么收钱全靠兑换码：确认到账后手工发一个给对方。

设备码

插件正在等主人确认的那些绑定请求；长码只在该插件手里，这里也看不到。
