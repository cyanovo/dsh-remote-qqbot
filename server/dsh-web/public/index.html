正文的三种去向

  • 直接发到 QQ（默认）：正文切成几条消息发进聊天框，不经过服务器，不占次数。
  • 只存服务器：正文存在本站，QQ 里只有一句摘要。
  • 存服务器 + 链接：与上一档相同，通知里多一条查看完整回答的链接。

后两种需要先在 DSH 设置里打开「允许上传正文」开关，它默认关闭。

额度与保留期

  • 免费版：登录后每天 100 次完整查看，记录保留 5 小时，按北京时间 0 点重置。
  • 付费版：¥2.99 / 30 天，每天 1000 次，记录保留 48 小时。再次兑换时在原到期时间上累加。
  • 记录到期后从磁盘删除；也可以在账号页提前清空记录，或连账号一起注销。
  • 保留期短是因为服务器只有 1.6G 内存、40G 硬盘，还要同时运行网站和机器人。

怎么装

两种装法，任选一种：

  • 让 DSH 自己装：教程第 2 章 有一段可以直接复制的文字， 粘进 DSH 的输入框发出去，它会自己装好、核对版本，再提醒你重启。
  • 自己敲一条命令：dsh plugin --profile desktop add github:cyanovo/dsh-remote-qqbot （dsh web 起的把 desktop 换成 web）。 插件仓库：github.com/cyanovo/dsh-remote-qqbot —— 想先看代码、或想自己改，从这里进。

装完重启 DSH，在设置里填好 QQ 机器人的 AppID 和密钥即可使用，不需要在本站注册。 只有想把完整回答存在自己账号下、并拿到可点的链接时，才需要绑定一次。

常见问题

为什么免费版只保留 5 小时？
服务器容量有限：1.6G 内存、40G 硬盘，还要同时运行网站和机器人。需要更长的保留期可以用付费版；长期存档建议存在自己电脑上。
QQ 里那条链接点开是空白？
QQ 只接受 http://大写域名/路径 这种形式，端口会被丢弃，因此链接都按这个规则改写。如果仍然打不开，通常是这条记录已经过期。
我的密码安全吗？
密码用 scrypt 加盐存储，服务端不保存明文；登录状态是 HMAC 签名的 HttpOnly cookie。插件的发布令牌只保存 sha256，绑定用的 8 位短码单独泄露也换不到任何权限，必须登录后确认。
会上传我的聊天内容吗？
默认不会。默认方式把正文直接发到 QQ，不经过服务器。上传只发生在打开上传开关、并选择后两种方式之后。
